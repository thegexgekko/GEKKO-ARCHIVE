# GEKKO ARCHIVE V0.7.1 Alpha — 30 octobre 2026

Windows 11 uniquement. Sources GitHub ; installateur NSIS construit et testé localement par l'auteur.

## Fonctionnalités validées sur Windows 11

- V0.6.3 : suppression d'éléments dans une archive ZIP et dans une archive 7z.
- V0.6.4 : formats de création ZIP, 7z, TAR, TAR.GZ, TAR.XZ, TAR.BZ2 ; lecture/extraction ZIP, 7z, RAR, TAR, GZIP, XZ, BZIP2, ZSTD, ISO, CAB.
- V0.7.0 : exécutable installé par NSIS, ouverture de fichiers par double-clic.
- Menu Windows 11 : correctif de reconnaissance des archives ZIP et des commandes auparavant grisées, validé avec MSIX de développement.
- V0.7.1 : compression ZIP/7z et extraction « ici » / « vers un dossier » par clic droit sans ouvrir la fenêtre principale ; commande « Ouvrir » conservée.
- Fenêtre d'ouverture réduite à 960 × 630.
- Démarrage à froid par double-clic optimisé : auparavant environ 5 secondes pour afficher le contenu ; désormais quasi immédiat, comparable à WinRAR, d'après l'essai utilisateur sur la même archive.

## Taille mesurée par l'auteur

- Installateur EXE : 7,51 Mo.
- Application installée : 17,4 Mo (hors composants système partagés tels que WebView2).

## Reconstruction

- Le projet repose sur React + Tauri 2 + Rust, plus l'extension C++ native du menu contextuel Windows 11.
- Pour reconstruire l'installateur optimisé, utiliser `CONSTRUIRE_INSTALLATEUR_OPTIMISE_V071.bat` après préparation locale des dépendances et ressources Windows de développement.
- Les packages MSIX, DLL, exécutables compilés, clés privées et certificats de signature ne sont **pas** versionnés.
- Cette version **Alpha n'est pas une publication stable destinée au grand public**. La désinstallation propre et les cas particuliers restent à vérifier séparément.
